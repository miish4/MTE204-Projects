# MTE204-Projects
Numerical Methods projects in MATLAB :) 

Project 1 covers solving basic resistive circuits using the built-in MATLAB equation solver, then also solving the circuit with a Gauss-Seidel with relaxation method. Then compared both methods to one another. 

Project 2 covers Finite Element Analysis/Method (FEA/FEM), in order to solve for unknowns in ideal heat conduction in an insulated rod as well as an ideal spring problem. Handwritten solutions were written previously for both, before implementing it into MATLAB in order to solve the matrices via Gauss-Seidel with relaxation.
